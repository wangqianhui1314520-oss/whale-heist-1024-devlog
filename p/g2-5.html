A 批：阻断级

QA-01 偶发「角色不响应移动」→ 三处一起改

已排除：焦点在按钮（activeElement=CANVAS）、碰撞体（barriers=[]）、平台边缘（grounded=true、y=490）。 新发现：当前 frame() 的世界更新被加了一道 !document.hidden 硬闸；一旦浏览器把页面判为隐藏（后台标签/最小化/部分无头环境），世界会静默停更——画面保持最后一帧、screen 仍是 none、没有任何暂停提示。这与"卡住但看起来一切正常"的现象完全吻合。

改法 1（src/main.mjs，删掉静默闸）

- if(world&&renderer&&['none','command'].includes(ui.screen)&&!document.hidden){
+ if(world&&renderer&&['none','command'].includes(ui.screen)){
安全性：input.mjs 的 visibilitychange → lost-focus 已经会在隐藏时暂停并弹出「暂停」面板，所以这道闸是重复的，且它的失败模式是"静默"。

改法 2（src/main.mjs frame 加看门狗，兜住未知根因）

// 放在 frame() 顶部，模块级声明 let wdTime=0, wdAt=0;
if(world&&ui.screen==='none'&&core.view().phase==='playing'&&!mustStayPaused()&&now-wdAt>600){
  const t=world.time||0;
  if(t<=wdTime+0.05){                        // 0.6s 内世界时间没走
    console.warn('[watchdog] world stalled',{t,screen:ui.screen,phase:core.view().phase,dash:world.player.dashCooldown});
    core.setPaused(false);input.clear();      // 强制回到可操作态
  }
  wdTime=t;wdAt=now;
}

改法 3（src/game/input.mjs:18，移动键不受按钮焦点影响）

- const action=this.actionFor(event.code);
- if(action&&!event.target?.closest?.('button')){
+ const action=this.actionFor(event.code);
+ const movement=['left','right','up','down','jump','dash','interact'].includes(action);
+ if(action&&(movement||!event.target?.closest?.('button'))){

风险：移动键在菜单里也能触发 → 但菜单打开时 getScreen()!=='none'，sample() 的下游（frame 的世界块）本来就不吃输入，安全；且这样还顺带修掉「点完剧情按钮后用键盘走不动」。 验证：QA_MODE=import5 node output/playthrough/play.cjs，看日志里不再出现 walkTo 卡死 ... phase=playing screen=none barriers=[]。

QA-08 长按互动偶发不生效

根因是 mustReleaseInteract 只能靠"下次读到的 input.interact===false"来清，而 input.clear()／暂停恢复的时序会把它一直卡住。

改法（src/game/input.mjs keyup + src/main.mjs 接线）

// input.mjs：keyup 里补一条
window.addEventListener('keyup',event=>{
  this.keys.delete(event.code);
  if(this.actionFor(event.code)==='interact')this.onAction('interact-released',{});
});
// main.mjs 的 act() 里加一个分支（放在 switch 里任意位置）
case 'interact-released':if(world)world.mustReleaseInteract=false;break;

风险：极低（只是让"松手"这个事实立刻生效）。 验证：QA_MODE=import5，日志里不应再出现 [重试] 换房未生效 / 广播未能关闭。
