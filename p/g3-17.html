《鲸鱼魔盗团》最终暴力测试与视觉验收

日期：2026-10-25，北京时间。验收对象：当前源码和由它重新生成的 dist/，含本日后续合入的剧情完整展示、对白避让和剧场分支改动。

结论与适用范围

本地参赛交付门槛：最终自动验证 25/25、正式部署包浏览器验收 11/11，通过。 本轮覆盖五章机制、13 个房间的视觉构成、异常输入与恢复、键鼠及手机横屏模拟、剧情分支、构建一致性和交付包完整性。剧情并行修改结束后，已重新构建并复验稳定版本；当前结果以所链接 JSON 为准。

这是一份有证据范围的发布候选验收。实际手机 GPU、多指硬件手感、Safari/Firefox、长期真人游玩和首次体验约二十分钟仍需实体设备与玩家验证；本报告不以自动通关时间或桌面触屏模拟替代这些结果，也不以绿灯宣称所有设备零缺陷或商业竞争力已被客观证明。

真实浏览器与视觉验收

当前生产包使用本机 Edge 的独立临时上下文测试，仅访问自建 127.0.0.1 服务。测试不读取或覆盖玩家在正式 8766 地址的存档。脚本自行启动和关闭测试服务及浏览器。

  • 标题、章节航图、契约、设置、五章首房间、行动指南、航图、指令、记录及三种剧情样式均保存当前画面。
  • 序章的观察、发令、撤离三项必要选择不能被跳过；实际键盘移动推进教学，暂停后刷新继续，教学进度保留。
  • 844×390、740×360、640×360 横屏均检查七个触控按钮：命中区至少 44×44，按钮在视口内；确认按钮可见，非法文本不能执行。
  • 小横屏剧情关键词至少 44px 高、13px 字号；顶部控件在安全区域；竖屏提示后回横屏保持暂停，再由玩家恢复。
  • 剧场三种样式和全部可选择分支逐项检查，浏览不修改存档。12 段剧情、20 个版本的完整推进另由 verify-story-theater.mjs 验证。
  • 13 个房间另外以正式生产模块、资源和 HUD 生成带明确标记的视觉夹具。这些图用于检查图层、地形、角色与机关构成，不作为穿越房间或通关证据。

共 45 张当次画面，见 视觉审阅页；点击缩略图可看原尺寸。复核未见缺图、人物横向拉伸、主要操作被遮住或按钮超出所检视口的阻断问题。完整证据列表以 JSON 中的 screenshots 为准，历史失败截图不代表当前验收结果。

性能证据的边界

浏览器记录三组各 599 个有效 requestAnimationFrame 间隔：1280×720 标准画质、120 次暂停切换之后，以及 844×390 触屏模拟。JSON 保存中位数、P95、超过 50ms 的帧数、JS 堆和各层 Canvas 尺寸。桌面主要绘制层为 2560×1440，触屏模拟为 1920×1080。

这些是当前机器的无头浏览器观测，受同时运行的任务和浏览器调度影响，不能换算成真实手机 FPS 或长期无内存泄漏结论。检查期间未发生页面异常、控制台错误/警告或生产资源请求失败。

本轮新增修正与交付一致性

  1. 没有适用目标时，队友提示改为“当前房间没有这位队友可处理的目标”，避免误导玩家认为整章协作已经完成。
  2. 随机主流程脚本支持并校验真实生效的 MSTRESS_STEPS / MSTRESS_SEED；以前固定 2000 步的限制已去除，报告记录实际步数和种子。
  3. 新增可重复运行的 scripts/qa-browser.cjs，提供真实浏览器交互、视口尺寸、截图、资源诊断、性能采样和源包一致性门槛。
  4. 验收期间探测到剧情源码继续更新而 dist 未同步，曾明确判定构建一致性失败；保留新修改并重新构建、复验后才形成当前结论。
  5. 提交说明删除未实现的“连击/队友信任”描述，明确默认指令仍消耗 AI Token；两种游戏 ZIP 重新生成并进行 CRC、哈希与内容比对，结果见 最终交付验收.json。

重跑

在游戏目录运行：

.\scripts\verify-all.ps1
$env:FUZZ_SEEDS='6'; $env:FUZZ_FRAMES='1400'; node scripts/fuzz-world.mjs
$env:MSTRESS_SEED='659918'; $env:MSTRESS_STEPS='20000'; node scripts/verify-stress-main.mjs
node scripts/verify-expanded-campaign.mjs --all
node scripts/qa-browser.cjs

浏览器脚本需要 Playwright 和 Edge；可设置 PLAYWRIGHT_MODULE 为本机模块位置、QA_BROWSER 为已有浏览器可执行文件。游戏运行本身没有这些开发依赖。浏览器日志及画面位于 output/final-acceptance/，交付 ZIP 的大小、文件数和 SHA-256 位于 交付包校验.json。
