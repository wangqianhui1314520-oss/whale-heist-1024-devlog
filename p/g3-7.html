《鲸鱼魔盗团》作品说明

一句话介绍

一款把“与 AI 沟通”变成实际玩法的横版小队动作解谜网页游戏：你扮演 DeepSeek 鲸尾少女，带领 Grok、Claude、GLM，在海底机房中破障、调度、取证，并让全员安全返航。

作品信息

  • 作品名称：鲸鱼魔盗团（Whale Heist）。
  • 类型：单人横版平台动作、机关协作、轻策略与剧情探索。
  • 体验方式：浏览器直接游玩，无需安装、注册或 API Key；推荐电脑，也支持手机横屏触控。
  • 内容规模：五章主线、十三个房间、互动序章、章节挑战和独立剧情剧场。
  • 目标时长：首次主线体验约二十分钟，为设计目标，仍需真人游玩校准。
  • 创作背景：2026 年 1024 创作活动的游戏参赛作品。

故事与目标

在虚构的深海世界中，一支性格各异的 AI 小队登上鲸艇，进入被机关与巡逻封锁的机房。玩家需要取得任务资料、调查行动记录、处理公开信息的风险，并在最后一章完成集结、装载和限时撤离。喜剧对白与调查线索贯穿行动，故事围绕“指令是否清楚、结果是否核验、行动后是否收好尾”展开。

五章依次为《纸窗入港》《简历风波》《复查勿扰》《战报公开》《闭舱返航》。角色与事件为虚构表达，游戏不接入真实攻击目标或攻击工具。

核心玩法

玩家直接操控主角移动、攀梯、跳跃和冲刺，同时选择队友、指定场景目标、确认行动。Grok 负责破障，Claude 改变巡逻，GLM 复查陷阱。普通节点需要两次独立冲刺，背包最多携带三块资料，取到资料后还要规划返回鲸艇的路线。

每次 AI 行动消耗 AI Token；默认方案与增加限定词的精确方案，形成范围、风险与资源之间的取舍。地图补给与证据整理提供有限补充。第五章要求先在远端信标集结三名队友并带齐资料，再确认装载、启动六十秒撤离，最后返艇交付并登艇。

特色与创新

  1. 把提示词变成战术选择。 “说清楚”影响队友行动范围与后续风险，精确约束需要付出有限资源。
  2. 先预测，再行动，再复盘。 “回声预测”免费展示指令影响、可能反应和返程提醒，指令记录帮助理解后果。
  3. 返程也是关卡。 已打开的路径、移动的守卫和处理过的机关会影响返航，要求玩家为回程保留资源。
  4. 证据与风险判断。 证据链拼图、公开摘要／封存／待核验的记录选择，让调查与行动形成反馈。
  5. 可复玩的展示方式。 主线解锁章节挑战；章节展示供快速审阅，不写入正式成绩；独立剧情剧场支持三种美术样式与分支浏览。

实现与 AI 协作

游戏采用原生 JavaScript ES Modules、分层 Canvas 2D 与 HTML/CSS 界面，实现规则、世界模拟、渲染和 UI 的分层结构。构建脚本生成可独立托管的静态目录，无第三方运行依赖，也无需在游玩时调用在线大模型。

AI 参与方案讨论、代码实现、测试和视觉资产生成；图片生成记录、提示词与资产校验信息保存在资产目录和相关文档中。游戏中的 AI 队友由本地规则驱动。

完成度与验证范围

当前具备五章可玩主线、平台碰撞、机关协作、资源管理、章节存档、暂停重试、结算、剧情剧场与触控操作。2026-10-25 发布前重新运行的本地自动验证为 25/25 通过。已有正式包浏览器验收覆盖桌面与横屏触控模拟，详见《最终暴力测试与视觉验收》。

实体手机性能、多指操作、Safari／Firefox 兼容性与首次通关时长仍需进一步验证。
