剧情满屏与绘制优化 · 2026-10-25

本地源码与正式构建已完成更新。原公开试玩链接未发布新版本：当前会话没有可用的线上发布连接。

变更

  • 电影、实景、分镜三种剧情风格铺满游戏视口；图片保持比例并按需要裁切，对话和操作按钮叠放在画面上方。
  • 修正电影缩放动画起始时露边、独立剧场的行内 contain 设置及章节列表的旧 PNG 引用。
  • 预加载当前剧情与下一场景图片，保留有上限的图片缓存。
  • 剧情背景、历史内容和布局仅在状态变化时更新，减少重复 DOM 操作。
  • 标准及低画质模式将游戏画布重绘上限设为 60 次/秒，物理与输入沿用原有的 60 Hz 固定更新。
  • 剧情、暂停、菜单和页面隐藏时停止游戏画布重绘；返回游戏后恢复绘制。
  • 本地服务器补充 WebP、MP3 的正确内容类型，HTTP 检查同步更新。

验证结果

  • 正式包：148 个文件，缺失引用 0。
  • 主流程回归：8 项通过，含 180 Hz 回调下的绘制频率、遮罩暂停绘制及恢复行为。
  • 剧情 UI 和独立剧场回归通过。
  • 最终完整浏览器验收：11 项通过、0 失败、0 浏览器诊断；覆盖五章操作、三种剧情风格、640/740/844 宽手机横屏、存档恢复及 13 个房间的渲染夹具。
  • 定向实测：桌面 1280×720、触控模拟 844×390 / DPR 3，各三种剧情风格均覆盖整个游戏视口，图片成功解码，标题及继续按钮可点击。
  • 定向实测记录的游戏画布绘制频率约为桌面 55.3 次/秒、手机模拟 58.5 次/秒；暂停、菜单、三种剧情画面期间均为 0 次。恢复后重新绘制。

这些是本机浏览器和手机模拟结果，不代表实际手机的性能，也不是严格的同条件优化前后性能对比。完整验收首轮性能采样仍观察到 10 个超过 50 ms 的回调间隔，因此不能承诺消除所有卡顿。
