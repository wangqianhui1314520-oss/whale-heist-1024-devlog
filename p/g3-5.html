人物动作稳定性修复 · 2026-10-26

本轮修复 Grok 持续向同一方向行走时，看起来反复左右转身的问题。

原因与改动

旧行走循环为 idle → walk → walk → idle → walk → walk。Grok 的待机与迈步图中，斧头、头发和身体轮廓差异很大，每 0.3 秒插入待机图会造成武器换边、人物转身的观感。正常跟随重现未发现朝向变量持续左右抖动，因此本次在动作采样层修复。

  • 四名角色行走全程使用当前方向的 walk 原图，停止后才恢复待机。去除行走中的整体拉伸，将起伏限制为 1 个逻辑像素，保留固定轻微前倾。
  • 主角冲刺和 Grok 破障全程使用当前方向的 skill 原图，避免活动途中插入行走图。Grok 持续破障时不再每 0.25 秒重播身体起手动作。
  • Grok 的水流和冲击特效继续按任务时间播放，与落定的身体姿态独立计时。
  • 物理移动、导航路线、任务耗时与关卡规则没有改动。

修改入口：src/render/character-motion.mjs。dist/ 已从源码重新构建。本轮没有覆盖旁边的历史发布快照，也没有发布在线站点。

验证

以下检查通过：

  • node scripts/verify-character-motion.mjs：40 个原图采样区、Grok 左右各 180 次连续实际 drawImage 取样、停止恢复待机、破障姿态与独立特效、减少动态效果设置。
  • node scripts/verify-rendering.mjs：完整绘制链、主角运动和跳跃、指令预览兼容。
  • node src/core/verify-core.mjs、node scripts/verify-art.mjs、node scripts/verify-world.mjs、node scripts/verify-main-flow.mjs；世界验证包含五章输入驱动通关。
  • node scripts/build-game.mjs、node scripts/verify-build.mjs：正式部署目录生成及资源引用验证。
  • node scripts/qa-character-animation.cjs：正式 dist，桌面 1280×720、手机横屏 844×390 / DPR 2 浏览器模拟，正常 UI 输入验证左右移动、跳跃、下落、冲刺和 Grok 指令。

浏览器另有明确标记的独立渲染夹具：Grok 左右各 120 次连续行走取样、各 70 次持续破障取样。这些夹具验证正式采样器和图集适配器，不作为真实游玩记录。

验证报告：browser-report.json。方向对照：grok-walk-directions.png。实机画面：电脑、手机模拟。

美术边界

仍沿用现有五种关键姿态和程序动效，没有把同一张图的六拍变换称为六张独立步态图。本轮修复轮廓跳变、错误混帧和反复起手；完整左右脚交替步态与专用攀爬图仍需新增美术。
