《鲸鱼魔盗团》下一版体验与玩法拓展方案

设计日期：2026-10-24。状态：下一版设计提案，以下新增功能不代表当前试玩包已实现。保留五章、DeepSeek 主角与 Grok／Claude／GLM 三名队友，以及横版固定镜头方向。

版本目标

让玩家经历“观察机房 → 用提示词组织行动 → 看见小队执行 → 搬运成果 → 发现自己的公开记录成为线索 → 调整计划并撤离”。动作、提示词和剧情围绕同一条因果链展开。

当前首版已具备五章物理流程、默认／精确指令、三格搬运、广播、存档、重试和结算。主要缺口是情境教程、持续剧情、地图事件的因果反馈、完整设置，以及指令编排的阅读与操作体验。当前完整熟练输入脚本为 49／142／92／78／103 秒，总计约 7 分 44 秒；它证明可通关，不代表首次真人时长。下一版仍以首次主线约 20 分钟为调优目标，支线额外约 3—5 分钟，不强制等待。

一、主菜单到通关的完整流程

首次进入 → 主菜单 → 约 30 秒互动序章（观察、发令、撤离三处必选选择） → 第一章边玩边学 → 章末回顾 → 船上简报 → 第二／三章渐进教学 → 第四章战报反转 → 第五章准备与撤离 → 调查笔录式总评 → 重玩、挑战或剧情回看。

主菜单使用鲸艇内部或停靠码头作为动态场景：主角在航图旁，小队做短待机动作，水面、灯、纸页提供低强度运动。菜单文字区保持干净，背景不承担必读信息。进入游戏的主按钮始终只有一个视觉重点。

状态主按钮次级入口与反馈
无存档开始行动章节、设置、行动指南；不同时铺开四种游戏模式
有存档继续第 N 章 · 章节名显示从本章入口或检查点恢复；重新开始降为次级入口
主线完成重返鲸艇章节挑战、调查档案、已看剧情、角色与提示词图鉴

有进度时重新开始，应说明将替换哪份航程，并允许取消；保留一个自动备份。章节展示放进章节页或附加内容，继续明确标记“不计正式航程”，避免首次玩家误入第四章。主菜单、暂停菜单均能进入同一个设置页，返回时回到原位置。

暂停提供继续、设置、当前任务、指令记录、从检查点重试、重新开始本章、返回主菜单。切后台继续保持暂停，不自动恢复。游戏加载失败给出重试和返回入口，加载期间防止重复出发。

结算先显示一句具体成果，例如“打开回程桥，带回四份资料”；随后展开当前评分原因和操作回放。保留已有每章 100／主线 500 的规则，新增速度、提示词花费等先做统计，不暗中计入既有分数。按继续后再提交本章结果和下章存档。

失败页说明本次失败来源，提供近处危险位置和最后一条指令的回看。主按钮为从检查点再试，另有本章重来和查看提示。检查点是同一份完整状态快照：生命、物品、预算、公开记录、事件、用时一起还原，不能换房刷新奖励或回退消耗。挑战模式从章首计时，辅助模式成绩单独标记。

二、设置与辅助功能

优先级内容约束
P0总音量、音效音量、字幕字号、减少动态、降低闪烁、重新查看操作立即生效并保存；尚未加入 BGM 前不显示空的音乐滑块
P0指令编排时暂停、教程提示开关剧情体验默认暂停，挑战可保留原有限慢动作规则；阅读弹窗不推进撤离时间
P1键位重设、左右手触控布局、按钮大小／透明度、点击或长按互动教程、HUD 按真实设置更新；触控命中区继续至少 44×44
P1对话速度、自动播放、已看剧情跳过、剧情回放关键新机制须可手动读完；跳过剧情仍正确结算事件
P2全屏、粒子档位、存档导出／导入导入校验版本；清空存档放独立危险区并说明范围

初版先提供“剧情体验”和“章节挑战”两套清楚的规则，不同时引入多套难度参数。新手可打开安全提示、延长预警和战术暂停；辅助不会替玩家选择支线或提示词。

三、新手教程：在第一章里完成第一次成功

第一章前 60—90 秒是安全教学区，计入第一章约三分钟目标；通过实际事件推进，一次只显示一个动作。重要说明等待玩家确认，不能六秒后自动消失。已完成操作不重复要求；老玩家可以跳过。

步骤场景安排完成判定与反馈
移动码头地面亮起短路径玩家真正到达目标；脚下和鲸尾给出反馈
爬梯与跳跃一段短梯、一处安全缺口到达平台并落地；按当前键位或触屏布局提示
冲刺节点无守卫的蓝色节点首击出现清楚裂纹；第二次独立冲刺破坏并拾取
小队合作一道主角撞不开的纸窗选 Grok、选目标、看预览、确认，待障碍实际破开后推进
背包与交付收集、回艇、持续互动三格容量和负重可见；交付进度完成才算学会
登艇船上出现明确新提示说明“交货完成，松开后再按住登艇”，不把两次互动混在一起

第一章只教主角和 Grok。第二章用安全演练比较 Claude 的默认与限定效果，提供一枚标注清楚的训练预算；第三章再教 GLM 的范围与报警代价。新机制先让玩家在安全环境成功一次，再放进真实危险中。

卡住提示按需分三层：先描述目标，仍停滞后指向可用工具，最后由玩家主动查看路线示范。触发依据为缺少进展和重复失败，发呆或看剧情不算失败。不自动操作、不悄悄变更机关。提示可回看，图鉴在安全时打开。

四、提示词成为可玩系统

把现有“直接执行／说清楚一点”发展成可视化指令编排。玩家逐步学会指定对象、限定范围、定义停止点。首轮以有限卡片和确定规则实现，文本与图形预览共同表达结果。

基础结构为：让【队友】对【对象／标记】执行【动作】，附加【一组约束】。

队友、合法对象和基础动作免费。第一版每条指令最多装一组约束，消费一枚现有“限定词”；约束组可以是一句完整表达，不按汉字数量收费。后续确有组合谜题时，再开放第二个约束槽与条件执行。

队友免费默认方案一枚限定词能换来的控制默认方案的主动价值
Grok沿当前通道冲锋，破开沿途合法障碍和节点指定处理一个目标，并在标记处结束可以连开多个节点，适合快速搬运和打开支线
Claude引开附近同层的多名守卫只引指定一名，保持另一条路线的巡逻关系一次腾出多个通道，便于连续行动
GLM扫描较大区域只扫描前方窄区，避开已标出的警戒器区域同时发现多个陷阱和额外档案线索

每种方案都有适用场景，精确指令不是固定正确答案。所有主线必须存在零限定词的可行路线；补给和精确控制提升效率、支线收益或安全性，不作为必过门票。

编排流程：选择队友 → 选择对象 → 对比方案／装约束 → 队友复述 → 查看场景预览 → 确认执行。示例：“Grok，处理蓝色隔板，只处理这一处，到标记停。”面板同时显示沿途目标、结束点、费用和当前风险。

预览与真实执行共用同一套范围、对象与路径校验，不能画一条安全线却执行另一条路线。移动守卫的未来位置不保证：预览显示当前对象和可确定的作用区域，明确哪些结果受时机影响，不伪造“成功率 99%”。队友状态显示赶路、执行、完成和冷却。

当前部分章节只有固定技能点，下一版逐步改为对有标签的场景对象发令：可破坏物、同层守卫、诱饵标记、扫描区域。剧情关键目标继续登记，普通对象允许玩家自己选择。MFA 门标注不可开启，不出现在可破坏目标列表中。

执行后给出短回执：“打开 2 个节点”“引开 1 名守卫”“发现 2 处陷阱，惊动 1 个警戒器”。回执可展开成指令记录，结局回放采用同一份真实数据。收藏三条常用模板即可，不先做复杂的提示词商城。

自然语言输入放在卡片系统稳定之后：输入短中文，解析到已解锁的有限句式，标出识别到的对象与约束，再确认。不能识别的部分直接标注，并提供可替换卡片；不猜测执行，不静默丢弃约束。无需联网模型或 API Key，后续接模型也只生成候选计划，仍经本地规则验证并由玩家确认。

费用边界：预览、编辑、取消未开始指令、无效对象和不可达目标不扣费；开始执行扣费。由系统寻路故障导致无法执行时返还对应预算，回执只结算一次；玩家主动在已生效后中断不自动刷回资源。教学资源与正式资源分开标记。

进阶内容留到 P2：最多一条等待条件，例如“守卫转身后执行”；或两名队友的有序接力。初期不要同时加入条件、循环、并发与任意自由聊天。

五、五章不变，扩展空间和事件

建议每章两张相邻的固定镜头主场景，组织为“准备／观察 → 主行动 → 变化后的返程”三段节奏。前三章各有一个可选小夹层，合计十张主场景、三个可选夹层；它们仍属于五个章节，没有十三份独立结算。先做第一章样板验证节奏，再扩其余章节。

每个房间保持 16:9 全景，不为放大地图把平台和文字挤满一屏。门口短转场连接房间，提供可展开房间总览。当前舞台、平台与机关图集可以复用，入口、纸窗、招聘板、校验灯、广播塔和返航信标承担不同地标。

章／主线目标主场景与三段体验支线与关键事件
一 纸窗入港，约 3 分钟码头教学 → 纸窗机房 → 展桥后的快速回艇高处档案夹层。破窗使电力管道亮起、返程桥展开；第二次回艇路线明显改变
二 简历风波，约 4 分钟招聘前厅观察两组巡逻 → 分拣机房组合诱饵与破障 → 锁定回程闸门误投的简历档案。默认诱饵能调走两人，精准诱饵只调一人；纸页有清楚持续时间，腾空的检查口实际可通过
三 复查勿扰，约 4 分钟校验桥学读扫描 → 管廊选择安全长路／风险近路 → 利用升降与静态梯路回程高处审计柜。扫描揭示陷阱周期；广域扫描触碰警戒器后先预告，再进入一轮调查
四 战报公开，约 5 分钟后台广播室看到旧记录 → 档案塔取两份任务物 → 远端站设置信标两份档案重放玩家此前的指令。关广播停止新增公开记录，旧记录保留；信标点亮下一章接应路径
五 闭舱返航，约 4 分钟接应前区检查返程 → 远端装载与三人集结 → 主动确认后的 60 秒撤离两处可选补给在不同支路。提前开门与路线选择影响撤离；开始后封存支线，重点只保留返回、交付和登艇

返程保留变化：新桥、单向水道、锁定开启的门、灯光指路、已经移开的巡逻。第一次探路，第二次利用自己的成果。必需物品总量先沿用现版，不增加节点血量，也不靠多搬同一种物品撑时长。

所有房间共用当前章节尝试状态，物品、节点、机关和剧情只结算一次。换房不重置冷却或刷新补给。任务进行中切房需明确处理：未开始动作取消且不扣费，已生效动作完成结算后转场；队友从门口正常入场。不能在不可见房间里默默执行或找不到队友。

每条近路都保留静态梯路作替代，升降台不是唯一出口。巡逻梯口设置安全观察台，诱饵落点避开玩家必须长按的机关与交付点。机关、提示词预算、队友位置三者都不能导致主线永久软锁。

六、事件导演与重玩价值

每章约三次主线事件和一次可选事件，每次都有触发条件、世界变化、声画反馈、记录与保底路线。优先作者编排，确保第一次体验能理解因果；重玩再加入明确展示的变体。

事件触发玩家看到的变化保底
纸窗供电Grok 实际破窗管线逐段亮起，桥展开，相机轻提示返程方向原梯路仍可返回
简历潮Claude 诱饵实际生效同层守卫离岗，纸页计时减少，检查口变空可等待巡逻自然经过
复查警报大范围扫描覆盖警戒器警戒器亮红、提示来源、扫描柱提前预告窄扫描或安全长路
战报被读进入广播室或完成前置任务调查屏幕重放此前真实行动提前关广播有专用分支，不强迫重开广播
返程变化关键任务物取得已知门改变状态，出现预先展示过的备用路线不封死全部出口，不把单次随机变化变成必败

主线事件不随机抽取消失，重要危险先预告。剧情体验先保证完整因果，章节挑战可增加公开选择的“巡逻加密／限定预算／关闭捷径”等契约；同一种种子与规则对应同一布局。支线用于角色笑点、档案、模板和路线，不堆装备养成。

守卫下一阶段可增加“发现 → 怀疑 → 搜索 → 返回”的简单状态，但探照锥必须与真实判定相同。先做好方向、巡逻边界、进入警戒的原因，再加追逐。守卫始终受自己通道限制，不漂移穿越平台。

七、剧情动画与事件改编

公开报告能支持的创作核心包括多模型辅助行动、攻击者开放目录暴露会话记录，以及请求制作安全研究员简历。报告对具体身份仍保留不确定性。“鲸鱼魔盗团”、角色个性、关卡机关、广播与剧情台词是本游戏的虚构改编，不当作真实过程的逐项复现。CrowdStrike 原始报告

把新闻转化为可操作的叙事关系：玩家给队友发出一句指令，世界出现结果；母舰公开这段战报，稍后的调查画面出现自己刚才说过的话。最终调查笔录从真实的发令、交付和报警记录生成。玩法使用虚构机房、资料箱与机关，不把真实地址或攻击步骤当作关卡题目。

剧情节点建议长度可复用的演出与交互
序章：接单出航约 30 秒自动演出，另加三处必选互动的操作时间航图亮点、Grok 一斧撞开舱内演示纸板、主角出发；完成观察、发令、撤离后立即交还操作
Claude 加入5—8 秒夸张简历展开，守卫被纸页吸引，直接接入第二章演练
GLM 加入5—8 秒扫描光显出原本不可见的陷阱，玩家接手选择范围
第四章反转12—18 秒屏幕出现玩家自己的指令与时间，镜头连向鲸艇公开广播灯
最后出航5—8 秒三人到齐、数据卡槽逐个亮起，玩家自行确认撤离
尾声：调查笔录12—20 秒交付成果、公开记录和小队状态生成对应结局与回放

采用现有关键姿态、头像、背景、纸页特效、分层位移和音效制作短过场，先补表情、眨眼、转头、惊讶和收尾动作，再决定是否制作更多逐帧素材。不先依赖长视频或全程配音。

对话支持点击／空格推进、自动播放、历史、跳过和回看。剧情播放期间暂停世界、计时和伤害；跳过仍提交同样剧情状态。已看剧情重玩时压缩。

第四章有两个清楚分支：广播仍开时，“我们一直在公开战报”；已提前关时，“新战报停了，旧记录已经被保存”。提前发现问题应得到台词、调查强度和结算的正向反馈。关广播不能抹掉旧记录，也不强制制造同样的疏忽。

八、视觉、UI 与 UX 的下一步

视觉重点保留深蓝、青色水流、暖金灯光、Q 版角色。下一步增加功能层次：背景降低细节对比，可站平台顶边稳定清楚，可交互目标采用统一轮廓，危险拥有独立形状和节奏。不能只用红绿区别状态。

主角、任务对象、危险是最高层；状态 HUD 次之；装饰和聊天退后。背包吸附、负重、交付、破坏与队友响应提供短促且一致的音画反馈；受击、落地和破障分别使用不同反馈，减少动态时关闭位移震屏与闪烁。

桌面：左上章节／当前行动，右上生命与现场警戒，底部小队与三格背包；目标只默认展示当前一步，其余展开查看。历史暴露与完整指令列表放在档案和简报，避免同时堆两个难懂数字条。场景名称与说明只在靠近、选中、首次出现时显示。

手机：收起大品牌与重复文字，保留章节、生命、警戒和一个可展开目标；双侧控制区可调整。指令编辑时收起移动控件，目标用大命中区和列表双入口，面板约占高度三分之一；文字保持真实屏幕可读字号。全景固定镜头继续保证平台关系可见，避免裁掉远端目标。

指令面板需要先修交互稳定性：当前随倒计时重建内容会导致键盘焦点丢失，应保持 DOM 结构，只更新费用、数值、范围和状态。默认／精确是两个可比较的方案，独立确认按钮提交；Enter 确认、Esc 返回，键盘可切换目标，返回仍保留刚才的选择。第一次编排暂停，让玩家读完；挑战才采用限时战术窗口。

剧情消息、警报、拾取与交付反馈分优先级排队。致命危险优先于插科打诨；同一事件不同时弹出对话、顶部消息和 Toast 三份文本。长对话放在安全位置或暂停场景，短气泡不挡落点。

九、实施顺序与验收

P0：完整主菜单与设置入口、续档信息与重开保护；稳定指令面板、战术暂停；第一章动作教程；第四章广播状态分支；重要消息优先级。完成后先让未读策划的人试玩首章。

P1：提示词约束卡＋队友复述＋路径／对象预览＋执行回执；短剧情系统；第一章双房间与变化返程样板；复制到五章；手机紧凑 HUD 与触控布局；章内检查点。现有可玩包保留为回退版本。

P2：有限中文输入、等待条件与双人接力、挑战契约、更多表情和动画、音乐、档案回放。只有前两阶段的理解与手感通过后，再扩此层。

实现建议采用本地数据驱动的 tutorials、story scenes、prompt rules、room events 和 settings 模块。事件与剧情标记由同一章节状态持有，关键事件都带唯一 ID；重复触发不重复奖励。新增房间／检查点需要升级存档版本，并把旧存档迁移到相应章入口。输入、预览和执行共享校验，渲染只负责显示。

验收关注实际行为：新人无需阅读策划能完成移动、节点破坏、第一次发令和交付；能复述免费默认与精确方案的区别；能指出一次报警的原因；知道最后六十秒尚未开始还是已经开始。测试按零限定词、默认指令、精确指令、提前关广播、满包切房、检查点恢复和手机操作分别覆盖。

最终以真人首次流程测量目标时长，记录卡住地点、误点、无效指令、死亡和看提示的原因。二十分钟来自有意义的观察与选择，不作为强制停留时间。
